# Gaharu Plus — Modern React.js & Framer Motion Landing Page

Website landing page interaktif, modern, dan berkelas tinggi untuk produk minyak balur herbal premium **"Gaharu Plus"**. Dibangun menggunakan **React.js (Vite)**, **Tailwind CSS v4**, dan **Framer Motion** dengan animasi fluid, transisi mulus, aset visual fotografi realistis bertema alam, dan testimoni autentik dari konsumen nyata.

---

## 🌟 Tech Stack & Arsitektur

- **Framework:** React 19 + Vite 6
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)
- **Animation Engine:** Framer Motion 12
- **Icon System:** Lucide React (vector-only, konsisten, bebas emoji struktural)
- **Typography:** Google Fonts (`Playfair Display` + `Plus Jakarta Sans`)
- **Visual Assets:** High-resolution realistic nature & botanical imagery + Foto testimoni konsumen nyata di `public/testimonials/`

---

2. **Testimoni 2 (`/testimonials/testi-2.jpg`):**

   - **Kisah:** Mengeluhkan kepala pusing keleyengan, napas ngap-ngapan, perut begah kembung, dan leher kaku. Setelah dibalur rutin, keleyengan sirna, napas plong lega, dan leher enteng tidak kaku lagi.

3. **Testimoni 3 (`/testimonials/testi-3.jpg`):**
   - **Subjek:** Dewi Susanti — Warung Umi Yayat, Desa Ciasmara 1, Kec. Pamijahan, Kab. Bogor.
   - **Kisah:** Mengeluhkan tangan pegal-pegal ngilu dan jari-jari kaku serta nyeri saat ditekuk. Setelah dioles dan dipijat lembut dengan Gaharu Plus, rasa nyeri dan ngilu hilang tuntas, jari lentur kembali.

## 🚀 Cara Menjalankan Proyek

### 1. Menjalankan di Mode Development
```bash
npm run dev
```
Buka browser di tautan lokal: **`http://localhost:3000`**

### 2. Membangun untuk Produksi (Production Build)
```bash
npm run build
```
Hasil kompilasi siap saji akan berada di dalam folder `dist/`.

### 3. Menguji Pratinjau Build Produksi
```bash
npm run preview
```
